# Học Tiếng Anh

Web app flashcard học tiếng Anh: Oxford Phrase List (750 cụm từ) và Oxford 5000 (4957 từ), có IPA giọng Mỹ, phát âm, nghĩa tiếng Việt và câu ví dụ.

Cài lên iPhone: mở trang GitHub Pages bằng Safari → Chia sẻ → Thêm vào MH chính.

Danh sách từ và bản ghi phát âm lấy từ Oxford Learner's Dictionaries. IPA, nghĩa tiếng Việt và câu ví dụ do AI soạn, có thể có chỗ chưa chuẩn.
